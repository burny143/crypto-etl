# Data Contract: Signal Event

## Purpose

Define the schema for an individual signal event — a BUY, SELL, or HOLD signal on a specific bar, traceable to a specific strategy version and research run.

## Status

**DRAFT** — Not yet implemented. Chart markers exist only in the client-side `signalChartMarkers[]` JS array, with no persistence or traceability.

---

## Schema (Proposed)

### `signal_events` Table

| Column | Type | Required | Description |
|--------|------|----------|-------------|
| `signal_id` | UUID | ✅ | Primary key, immutable. Unique identifier for this signal instance. |
| `symbol` | TEXT | ✅ | Trading pair (e.g., "BTC-USDT") |
| `timeframe` | TEXT | ✅ | Bar interval ("1h", "4h", "1d") |
| `candle_timestamp` | TIMESTAMPTZ | ✅ | The bar open time for which this signal was generated |
| `value` | FLOAT | ✅ | Signal value in `[-1.0, 1.0]` range. 1.0 = strong long, 0.0 = flat, -1.0 = strong short. |
| `classification` | TEXT | ✅ | One of: `BUY`, `SELL`, `HOLD`, `CLOSE_LONG`, `CLOSE_SHORT`, `FLAT` |
| `strategy_id` | UUID | ✅ | References `strategy_definitions.id` |
| `strategy_version` | INTEGER | ✅ | Version of the strategy that generated this signal |
| `parameters` | JSONB | ✅ | The specific parameters used (snapshot from strategy definition) |
| `research_run_id` | UUID | ❌ | References `research_runs.id` if this signal was generated during a research sweep |
| `validation` | TEXT | ❌ | `"in_sample"` or `"out_of_sample"` if from a research run |
| `reason_codes` | JSONB | ❌ | Machine-readable reasons for the signal (e.g., `["rsi_below_30", "volume_above_avg"]`) |
| `generated_at` | TIMESTAMPTZ | ✅ | When this signal was generated |

### Constraints

- `value` must be in `[-1.0, 1.0]` inclusive
- `(strategy_id, candle_timestamp)` should be unique — no duplicate signals for the same strategy on the same bar
- `reason_codes` must be an array of string identifiers

### Example

```json
{
  "signal_id": "sig_abc123-...",
  "symbol": "BTC-USDT",
  "timeframe": "4h",
  "candle_timestamp": "2026-07-25T00:00:00Z",
  "value": 0.8,
  "classification": "BUY",
  "strategy_id": "a1b2c3d4-...",
  "strategy_version": 2,
  "parameters": {
    "period": 14,
    "oversold": 30,
    "overbought": 70
  },
  "research_run_id": "run_xyz789-...",
  "validation": "out_of_sample",
  "reason_codes": ["rsi_crossed_above_oversold", "volume_above_20_avg"],
  "generated_at": "2026-07-26T12:00:00Z"
}
```

## Signal Value Semantics

| Value Range | Classification | Meaning |
|-------------|---------------|---------|
| 0.8 to 1.0 | BUY | Strong buy signal |
| 0.3 to 0.8 | BUY | Moderate buy signal |
| -0.3 to 0.3 | HOLD | Neutral / no signal |
| -0.8 to -0.3 | SELL | Moderate sell signal |
| -1.0 to -0.8 | SELL | Strong sell signal |
| -1.0 | CLOSE_LONG | Force-close long position |
| 1.0 | CLOSE_SHORT | Force-close short position |

> **⚠️ Disclaimer:** The numeric signal value is a derived technical indicator output, not a guaranteed probability of profit. Past signal performance (measured by strategy backtest metrics) does not guarantee future results.

## Current State (Before Implementation)

- Chart markers exist only in the `signalChartMarkers[]` JS array in `index.html`
- Markers are generated by `applyStrategySignals()` when a user clicks a strategy card
- Markers are cleared on: page reload, symbol change, timeframe change, data reload
- No signal_id is attached to markers
- No history of which signals were displayed
- Paper trades cannot be linked back to signals

### Frontend Integration (Proposed)

```javascript
// Future: load signal events from Supabase
async function loadSignalEvents(strategyId, runId) {
    const { data } = await supabaseClient
        .from('signal_events')
        .select('*')
        .eq('strategy_id', strategyId)
        .eq('research_run_id', runId)
        .order('candle_timestamp', { ascending: true });
    
    data.forEach(signal => {
        chartMarkers.push({
            time: signal.candle_timestamp,
            position: signal.value > 0 ? 'below' : 'above',
            color: signal.value > 0 ? '#22c55e' : '#ef4444',
            shape: signal.value > 0 ? 'arrowUp' : 'arrowDown',
            text: `${signal.classification} [${signal.signal_id.slice(0, 8)}]`,
            signalId: signal.signal_id  // For traceability
        });
    });
    candleSeries.setMarkers(chartMarkers);
}
```
